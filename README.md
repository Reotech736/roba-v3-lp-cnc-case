# roBa v3 LP CNC Case

CNC削り出し加工用に設計されたroBa v3 LP用アルミケースプロジェクト

## 概要

このリポジトリは、JLCCNC（オンライン見積対応）での発注を想定した、roBa v3 LP用のアルミ削り出しケースのCADデータを提供します。

### 特徴

- **CNC加工最適化**: 3Dプリント前提の形状を、CNC削り出しに適した設計に変更
- **アルミ素材対応**: アルミ6061/7075に対応
- **表面処理**: ビードブラスト、各種アルマイト処理に対応可能

## 元データについて

このケースは、[kumamuk-git/roBa](https://github.com/kumamuk-git/roBa)リポジトリで公開されているroBaの標準ケースを基に、CNC加工向けに改良したものです。
