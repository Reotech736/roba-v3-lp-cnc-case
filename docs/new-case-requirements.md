## 4. 上下の役割と固定方法の比較案

現時点の作業仮説は「上側でスイッチとPCBの相対位置を決め、下側を外して内部へアクセスする」。既存キーボードの支持条件が違えば変更する。上下ケースの締結とPCBの支持・固定は別の問題として扱い、ケースねじで基板を直接挟むことを前提にしない。

| 比較案 | 構成 | 決定前の確認 |
| --- | --- | --- |
| A: 底面ねじ＋上側タップボス＋位置決め段 | 第一比較候補。段で横位置を決め、ねじで上下を保持 | ボスとPCB・電池・配線の干渉、底面ねじ頭とスタンドの重なり、穴加工と工具進入 |
| B: 側面ねじ＋位置決め段 | 旧案の考え方のみ参考にする比較候補 | 側面の穴加工・皿座、薄壁、ねじ締付方向、ドライバー進入 |
| C: 通しねじ＋別ナット等 | 直接タップが成立しない場合の予備案 | ナットの保持空間、組立中の脱落、部品点数、整備性 |

位置決め段の隙間、挿入深さ、内側R、締結面、ねじの有効長と止まり穴余裕は新設計で定義する。ねじ穴位置は内部部品の禁止領域を置いてから決める。

## 5. 新設計の基準座標（提案、未実装）

- 左右各ケースに独立した座標を設ける。旧ケースの原点・組立変換は使わない。
- PCBの確認済み基準面をZ=0候補とし、+Zをキー側、-Zを底面側とする。X/Yの向きは実機の使用姿勢で一度定義して固定する。
- X/Y原点は検証可能な基板基準穴または基準輪郭から決める。包絡中心を機能基準と決めつけない。
- ケースの上下合わせ面と机への接地面はPCB面とは別のパラメータにする。先にケース高さを固定しない。
- スタンドの収納包絡、展開包絡、爪の操作空間は別々に管理する。

## 6. 設計を進める順番

1. 基板版・スイッチ・COROPIT・電池を特定し、モデルまたは実測情報の出典と単位を記録する。
2. 新しい座標系で機能部品の配置と、干渉させない空間を作る。モデル不足箇所は仮包絡と明示する。
3. PCB支持と上下分解の順序を決め、固定案A/Bを配置比較する。
4. 壁・底・ボス・合わせ面を新規履歴で作る。素材厚、工具進入、両面加工の保持を検討する。
5. スタンドくぼみと指掛かりを置き、残肉・締結部・操作部との干渉を検証する。先にくぼみ位置を固定しない。
6. 実物試験で収納・開閉・組立・操作・通信を確認し、JLCCNC提出用の部品別STEPと図面を用意する。

仮寸法での配置比較・設計作業は進めてよい。現物やモデルの不足を、適合・強度・通信を確認済みと扱う理由にはしない。ケース全体の新規CAD形状はこの要件整理時点で未作成。
