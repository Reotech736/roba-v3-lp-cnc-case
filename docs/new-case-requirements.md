# 新規ケースの要件（v21）

更新: 2026-11-08。現行の採用条件と未認定事項を記します。数値は概寸・仮設計を含み、発注仕様ではありません。最新の作業順は[再開メモ](next-session.md)。

## 方針

- roBa v3 LP、右側COROPIT対応の左右上下ケースを新規設計。ケース本体は旧設計の外形・厚さ・組立座標を継承しない。旧設計は嵌合・固定方法と、部品・穴配置を調べる参照に留める。
- 元STEP6点と旧モデルは変更しない。Fusion MCP/APIを優先し、現行v05の同じクラウドファイルを更新。
- アルミ削り出し、JLCCNCを予定。ケース自体は水平、折りたたみスタンドで傾斜を付ける。手元に3Dプリンタがなくても仮寸法で進行可。試作・発注は未実施。
- 今回はChoc側のみを配置基準とし、MX側の穴・ランドへ合わせない。

## 検査の扱い

部品間の体積重複、穴の閉塞・ねじ包絡、残肉、裏当て投影、理想平面への侵入を別々に検査。指定条件で0件でも、設計全体・実物適合・製造成立を認定したとは扱わない。v17で見落としたM2穴閉塞と外周張り出しはv18で修正、接地辺はv19、Choc向きと支持1はv20で修正済み。
