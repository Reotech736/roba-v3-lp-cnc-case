# CNC加工とは - 3Dプリントとの違い

## CNC加工の基本

### CNC加工とは
- Computer Numerical Control（コンピュータ数値制御）
- アルミなどの素材ブロックを、回転する刃物（エンドミル）で削って形を作る
- **削り出し加工** = 引き算の加工

### 3Dプリントとは
- 樹脂を少しずつ積み重ねて形を作る
- **積層加工** = 足し算の加工

## 重要な違い

### 1. アンダーカット（逆テーパー）

```
3Dプリント: OK          CNC: NG（3軸の場合）
    ┌─────┐              ┌─────┐
    │     │              │     │
    └──┐  │          ←  │  ┌──┘  ← 工具が届かない
       └──┘              └──┘
   内側に入り込む形       ※5軸CNCなら可能だが高価
```

### 2. 最小R（内側コーナー）

```
3Dプリント: 0mm可        CNC: エンドミル径に依存
    ┌──┐                  ┌──┐
    │  │                  │  │R
    │  └─                 │  └─○  ← エンドミルの丸み
    角が90°でOK            最小R 0.5mm～1.0mm程度
```

### 3. 薄肉（壁の厚さ）

```
3Dプリント: 0.8mm～      CNC: 2.0mm～推奨
     │││                    ┃┃┃
   薄くて柔軟               厚くて強固
   割れやすい               削り残しやすい
```

### 4. 柔軟性

```
3Dプリント: ツメ固定可     CNC: ネジ固定推奨
    ├──→  ←──┤             ○  ○
    柔らかく曲がる            剛性が高い
```

## JLCCNCの仕様（一般的）

### 加工可能範囲
- 3軸CNC（標準）
- 最大サイズ: 通常 200×200×80mm程度
- 最小加工径: φ1.0mm（エンドミル）
- 内側最小R: R0.5mm～

### 素材
- アルミ6061（一般用途、柔らかめ）
- アルミ7075（高強度、硬め、高価）
- その他: 真鍮、銅など

### 表面処理
- サンドブラスト / ビードブラスト（ザラザラ）
- アルマイト処理（各色）
- 無処理（削りっぱなし）

### 公差
- 標準公差: ±0.1mm
- 指定公差: ±0.05mm～（追加費用）

## CNC向け設計のポイント

### ✓ やるべきこと
1. 内側コーナーにR0.5mm以上を付ける
2. 薄肉部分を2.0mm以上にする
3. アンダーカットを避ける（または分割）
4. ネジ穴を設ける（M3推奨）

### ✗ 避けるべきこと
1. 90°の内側コーナー
2. 1.5mm以下の薄肉
3. 内側に入り込む形状
4. 柔軟性が必要な嵌合

## roBaケースで予想される問題点

1. **ツメ固定**: 3Dプリントの柔軟性前提 → ネジ固定に変更
2. **薄肉部分**: 1mm程度の壁 → 2mm以上に変更
3. **シャープコーナー**: 90°角 → R0.5mm追加
4. **複雑な嵌合**: 削り出しでは困難 → 簡略化
