# 設計整合性の再点検と修正（v27）

更新: 2026-11-09。現行v05のクラウドv27。保存・処理完了・未保存変更なしをAPIで確認。発注用ではない。v26の配線保持案より、この再点検記録を優先する。

## 発見と対応

| 再点検した項目 | 結果と対応 |
| --- | --- |
| 上側M1.6穴の周囲の肉 | 旧形状は外側のねじ外径から外面まで約0.476 mm。下側の1.1 mm壁の検査では見つからなかった。上側X13.8〜16、Y−27.6〜−18.2、Z−1〜4.5へ局所補強を追加・結合。2軸ともねじ外径D1.6の周囲の半径方向0.9 mmスリーブ全体を材料と比較し、欠損0。0.9 mmは比較寸法で、強度・加工の合格基準ではない |
| 補強の張り出し | 局所外形は意図して変更。上ケースの実ソリッド最大外接寸法は不変。構築線を含むOccurrenceのBBoxではなくBRepのpreciseBoundingBoxで照合 |
| ブラケットの腕と固定足 | 接続の上下断面を別々に調べ、3.2 mm²の接続材料を確認。薄い接触だけという疑いは該当せず、追加変更なし |
| 材料情報 | ユーザー指定により上下ケースへJLCCNCの6061-T6を設定。引張290 MPa、0.2%耐力240 MPa、密度2800 kg/m³は同社記載値。Fusion既定の鋼を置換。弾性率68.9 GPa・ポアソン比0.33等はFusion6061の代表値を継承し、供給保証値とは扱わない |
| 非金属ブラケットのSTEP | 独立出力用文書の既定鋼・密度7850が混入していた。材質未選定なので材料属性の参照グラフだけを出力から除去し、再読込して形状を照合。Fusion内の未選定非金属候補・カバー等の既定材料による重量は使用しない |
| 記録の不整合 | 主JSONの未解決項目が空、旧PCB接着候補寸法が現行風、古い表示管理案内、旧コミット状態の表現を修正。下ケースSTEPが空だった問題はv26で修復済み。今回は実体・材質と再読込まで確認 |

材料の一次資料: [JLCCNC Aluminum6061](https://jlccnc.com/help/article/aluminum-6061-cnc-machining)。記載は直径70 mm以上の試験片等の条件を含むため、購入する板材・薄肉加工品の保証値ではない。密度も同社表記2800を仮採用しており、一般に使われる2700との違いは調達時の確認事項。上下ケースだけの参考質量は約38.22 g／103.22 g。カバーの製法・材質、非金属受け・ブラケットは別途選定する。全体重心をこれらの既定材料から算出しない。

## 検証した範囲

- v26の承認済み587構成に対し、形状差は上ケース体積+84.772845 mm³だけ、変換行列差0。v27の基準へ更新後は587構成すべて一致。Choc46配置、23ステム上端、pin3除外、グループを維持。警告0。
- 62主要ソリッドと配線・詳細ソケットの指定検査、詳細Chocとケースの検査を実施。既存M2の4穴通路、新M1.6の2下穴・ブラケット通路・頭支持、工具2径×2軸、支持4・逃げ8、収納2か所と残肉2 mmを再確認。
- 接地辺の連続42 mmを照合。420対象の外接範囲から理想平面への正方向0〜90°持上げ条件を確認。実スタンドの運動・接地安定性を証明するものではない。
- 上下ケース・ブラケットのSTEPはローカル座標の単一ソリッドで再読込。体積差は上下で約5.4e−10 mm³以下、ブラケット約3.35e−5 mm³、最大境界差約3.6e−14 mm以下。全体F3Dと主JSONを更新。
- 元STEP6点・公開PCB1点・第三者参照3点の保存バイトをマニフェストのハッシュと照合。参照ファイルは変更しない。

根拠: [修正前](design-consistency-audit-v26-before.json)、[現行587構成・肉厚](design-consistency-audit-current.json)、[修正形状](design-consistency-correction.json)、[材料値](case-material-verification.json)、[STEP再読込](case-wire-bracket-step-roundtrip.json)。検査対象を限定した結果であり、設計全体の「干渉ゼロ」「製造可能」という判定ではない。
