# 電池線2本の独立40 mm経路（v28・確認用）

更新: 2026-11-09。現行Fusionはクラウドv28、保存・処理完了・未保存変更なし。**実線2本を模した幾何試案を確認用グループに追加した。結束済み配線の採用確定ではない。** ケース・ブラケット・電池受け等の実体候補はv27から変更していない。

## 変更の理由と範囲

従来のD3束モデルでは、1本の中心線長に対称端部分岐を足し、各線40 mmと比較していた。線の位置ずれ、曲げの接続、線同士の隙間は別々にモデル化していなかった。

今回の初期横並び案は2本の中心線が交差したため不採用。未加工の[不採用案](individual-lead-rejected-x-offset-study.json)と[検出記録](individual-lead-rejected-x-offset-verification.json)を履歴として残した。出口／はんだの意図した接触も一括衝突扱いした初期検査であり、その0距離をすべて不具合とは解釈しない。

次の試案はループを上下に分け、各線を出口点から基板B1の各はんだ位置まで独立に40 mmへ調整。直線・円弧で接続し、最後の基板側4区間は5姿勢とも同一座標を保持した。左右の呼称は幾何配置であり、電気極性を割り当てたものではない。

| 条件 | 今回の扱い |
| --- | --- |
| 電池／配線 | 42×20×5、基板電池パッドへ直付け。ユーザー指定40 mm／本、被覆外径約1 mm／本 |
| 出口点 | 仮のX−13、Y−30、Z−5.6±0.8。上下1.6 mm間隔は未測定の仮定 |
| 基板側 | 公開参照B1のX−2.38934／−0.38934、Y−19.341、下面Z0。実機版は未確定 |
| 曲げ中心線半径 | 出口側R1、主ループR3、基板直前R1.5。実線で許容される半径とは未認定 |
| 独立姿勢 | 下ケース・電池を0／2／5／8／10 mm下降。連続した柔軟変形を証明しない |
| 結束部 | 従来ブラケットとの体積重複は避けたが、受け面へ押し当てる動きと結束材の全経路・保持力は未検証 |

[経路JSON](individual-battery-lead-study.json)と[再計算スクリプト](../scripts/analyze-individual-battery-leads.py)。出口を含む全区間の中心線長は各40 mm。仮端点・線径・曲げ半径の許容差を含む製造仕様ではない。

## 検査対象と結果

各姿勢の414対象ソリッドに対し、外接範囲で遠方を除外し、残る対象はFusionの曲線・立体の最小距離と内部点判定で比較。上側・PCB輪郭・XIAO・Choc詳細・絶縁材・固定ブラケットを固定、下側・電池・受け・粘着層を同じ下降量とした。実ねじ・未モデルの銅箔／はんだ／部品・結束材全体はこの集合に含まない。

| 下ケース下降 | 線同士のD1表面間隔・名目 |
| --- | --- |
| 0 mm | 約0.2494 mm |
| 2 mm | 約0.2494 mm |
| 5 mm | 約0.2494 mm |
| 8 mm | 約0.2494 mm |
| 10 mm | 約0.1314 mm |

対象検査では、下記の意図した端点領域を除き、D1の半径余裕が負の箇所はなかった。閉じた状態は実際の2本のPipeソリッドでも表面間隔約0.2494 mmを照合し、体積は各31.4159265 mm³（直径1×長さ40の断面積×長さ）と一致。

**端点の限定除外:** パウチ出口から中心線0.8 mmは電池の単純直方体との接続領域、はんだ位置直前0.5 mmはPCBとの接続領域として、それぞれの相手だけから除外。残りの曲線は同じ相手にも検査し、他の部品と線同士には全長で検査した。実パウチの封止・出口と被覆剥き・はんだフィレットをモデル化したわけではない。PCB側の被覆包絡の終点は名目で下面へ接するため、正の余裕があるとは扱わない。

最小約0.13 mmは概寸OD1 mmに対する結果。実径・組立誤差が増えれば接触し得る。R1／R1.5の曲げ、電池出口、結束で経路が移動した状態は未認定。従来D3束包絡が個別2本を全域で包含するとも断定しない。主ループは別々に深さを調整しており、旧D3の確認結果をそのまま転用しない。

根拠: [閉状態](individual-lead-verification-gap0.json)、[2 mm](individual-lead-verification-gap2.json)、[5 mm](individual-lead-verification-gap5.json)、[8 mm](individual-lead-verification-gap8.json)、[10 mm](individual-lead-verification-gap10.json)、[保存時の照合](individual-lead-final-verification.json)。検査対象外を含む設計全体の干渉ゼロ・製造可能判定ではない。
