# 左ケースのLP着座修正と詳細XIAO参照

更新: 2026-11-08。この資料はクラウドv7の着座修正の履歴。現在は[詳細参照・固定部・指掛かりを加えたv9](choc-reference-and-cover-development.md)へ進んでいる。発注用ではない。

## 反映した変更

- 保護天板をZ=2.6〜3.8、厚さ1.2 mmへ変更。外周上端Z=4.5とM2ボス・穴は維持した。公称のスイッチ着座面に合わせた比較であり、実物係止の承認値ではない。
- 下側14角スイッチ包絡をPCB上面1.6〜フランジ下面3.8へ修正。上側15.2角×高さ3.5の保守的な包絡を23個追加した。斜面を最大角形で包む参照で、爪やソケットは含まない。
- カバーをX±9.3、Y−20.35〜2.4へ縮小。屋根Z=7.5〜8.7、壁厚0.8、壁下端Z=5.2。MCU主部上面4.87との公称差0.33、USB最高部6.06と屋根下面との差1.44。開いた下部と固定方式は未解決。
- D=3.0 mmという仮の取付位置で、23キーの押下掃引包絡を追加。18.8角、Z=4.15〜11.14。実キャップの内部形状や全傾きは表していない。
- 押下包絡と外周の間で3キーに約0.00002 mm³の微小な交差が報告されたため、上側だけに18.9角・Z=3.9以上の局所逃げを追加。除去量約0.01536 mm³。厚さ1.2の天板は削らず、M2ボス直径6の円内にも逃げを入れていない。左ボス円と逃げ矩形の最短距離は公称約0.05066 mmなので、加工時の稜線処理は別途確認する。
- 旧XIAO v2を77ボディの詳細参照として再利用。元は未変更。仮包絡は非表示で保持。[部品参照の方針](component-reference-policy.md)。

変更前v6は`cad/design/checkpoints/v05_cloud_v6_before_lp_seating.f3d`に保存。

## 続ける作業

カバー固定・上下の位置決め・詳細XIAOのリセット操作を詰める。カバー前側に小ねじ2本を置く案を調べたが、穴やボスはまだ作っていない。既存の狭い外周に無理に穴を置かず、USBとキャップの空間を維持した固定用座が必要。

[JLCCNCのねじガイド](https://jlccnc.com/help/article/threaded-hole-guideline)では、止まり穴の底に少なくとも穴径の半分の非ねじ領域を残すことを推奨している。M1.6を採る場合の切削タップ下穴1.25は[OSG資料](https://www.osg.co.jp/media_dl/flier/file/n_102.pdf)にあるが、採用径・ねじ長・加工対応は未確定。[JLCCNC発注ガイド](https://jlccnc.com/help/article/cnc-machining-ordering-guidelines)に合わせ、最終的には部品ごとのSTEPとねじ仕様を記載した2D図面を用意する。

その後、スタンド指掛かり・開閉と右COROPITへ進む。元の参照6点、旧XIAO、旧ケースは変更していない。今回分は未コミット・未push。
