# LP部品・COROPIT・内部配置の調査

更新: 2026-11-07。メーカー資料の確認、Fusion MCPによる参照測定、新しい内部配置の比較案。ケース本体と加工用データは未作成。

## 1. ユーザーが特定した部品

- スイッチ: [TALP Kailh Spring MINI リニア Choc V2](https://shop.talpkeyboard.com/products/kailh-spring-mini-chocv2)。一般的なChoc V1、Silent Miniの図面と取り違えない。
- COROPIT: [Kinoya公式](https://booth.pm/ja/items/6830658)のImagine Blackケース。レジン版として扱う。
- 電池: ユーザー概寸30×20×4 mm、写真ラベル250 mAh・3.7 V。端子、配線、保護部の最大外形は未確定。

## 2. Spring Miniとソケット

メーカー[Four Seasonsシリーズ](https://www.kailhswitch.com/mechanical-keyboard-switches/low-profile-key-switches/four-seasons-series-mini-low-profile-switches.html)からSpringの[CPG1353D01D01-24図面](https://www.kailhswitch.com/uploads/15927/files/CPG1353D01D01-24-data-sheet.pdf)を取得。最初の2ページを画像にして確認した。販売名・荷重と整合するメーカー候補図面だが、実物ロットの品番刻印を照合したわけではない。

| 図面から読んだ項目 | 値 mm（荷重を除く） | 設計での扱い |
| --- | --- | --- |
| 上側の外形 | 15×15 | キーキャップの外形・動作空間とは別 |
| 下側ハウジング | 13.95±0.05角 | プレート開口そのものの指定ではない |
| 軸上端からPCB側着座面まで | 6.40 | キャップ高さは別途必要 |
| 着座面より下の突起 | 2.20 | ソケット・はんだを含む実装包絡とは別 |
| 爪近傍の寸法 | 1.35 +0/-0.10 | 係止形状の寸法。推奨プレート厚と断定しない |
| 全ストローク | 2.8±0.25 | キーキャップ下面とケースの接触を確認する |
| 作動荷重 | 40±10 gf | TALP説明とも整合 |
| ソケット使用時のPCB参考穴図 | 中央φ5、接点側2×φ3 | はんだ面視。向き・回転を揃えて照合する |

公開v2のSW_MXフットプリントには中央φ5とMX系の接点穴・パッドがある。Spring Mini用ソケット穴の配置そのものとは認定できない。旧左基板に追加された40個のφ3穴は、主に20スイッチ分の対として配置されている。代表点では中央φ5穴に対する差が(-5,-3.7)、(0,-5.9) mm。Choc系接点穴を追加したという記憶とは整合するが、現行メーカー参考図の寸法・向きとの完全一致、親指キー3個、右基板、実機の加工状態は未確認。旧基板を正しいLP基板として採用しない。

ソケットの比較資料はメーカー[CPG135001S30図面](https://www.kailhswitch.com/uploads/15927/files/CPG135001S30.pdf?rnd=101)。図面1ページ目のRev C（2024-01-09）を画像で確認。平面図の全幅13.45±0.10、奥行6.85±0.10、高さ1.85±0.10 mm。13.15±0.15は別の投影方向の寸法なので、最大幅13.15として包絡を作らない。実物ソケットの型番・版、取付方向、はんだ量は未確認。

元top_L_LPをMCP/APIで測った主な開口は14.1角、局所段のZ=2.6〜3.8 mmで厚さ1.2 mm。これは既存ケースの測定値で、Spring Miniをアルミで確実に係止する保証ではない。次の上側設計では、厚い天板に直接同じ穴を開けるより、爪周辺だけ薄くする段加工、または交換可能なLPプレートを比較する。内角R、爪の退避、脱着工具、アルマイト後寸法を検討する。キーキャップは未特定のため上縁高さを固定しない。

## 3. COROPIT固定部と必要空間

公式説明から確認した条件:

- 25 mmボール、専用センサー基板とケースを使用。roBaにも対応する。
- レジン版（Imagine Blackを含む）はPLA版より約0.5 mm大きい。各面・直径・高さのどの寸法差かは未記載なので、全方向に片側0.5 mmを加算しない。
- roBa標準のM1.7 Torxねじを流用する説明がある。別機種の長いねじは内部に干渉する場合があり、突出長の確認が必要。

未変更bottom_R_LP_COROPITをMCP/APIで読み取り、同一直線上にφ1.7の穴2個、ピッチ16 mm、対応するφ3.7の座ぐりを測定した。[測定JSON](coropit-reference-mount.json)に元座標を記録。この穴径・座ぐり径は参照ケースの値で、新しいアルミ部品のM1.7クリアランス、公差、タップの指定にはしない。旧組立変換や穴の絶対位置は新設計に継承しない。

本体寸法付きCADは今回の公式資料調査では取得できていない。そのため新配置CADに、推測寸法のCOROPIT実体は置かなかった。取付ピッチ16 mmを比較候補として保持し、本体・基板・配線と球中心高さを独立に確認する。

可動域は、固定シェル内で回転するボール、指の操作空間、ボールの取り出し経路、モジュールを外す経路、ねじ締付工具を分けて扱う。ボール径25 mmだけで開口径・筐体高さ・取り出し経路は決まらない。樹脂シェルをアルミ開口で強く挟まず、脱着できる保持とする案を優先する。

## 4. 新しい内部配置の比較案

Fusionの02_designに`internal_layout_candidate_v01_NOT_FOR_MANUFACTURE`を別名保存した（クラウドv3）。公開基板から作成済みの独立参照を複製し、電池本体・仮余裕・ねじ軸マーカーを配置した。元STEP、旧ケース、旧基板、基板参照v01は変更していない。

座標は各側の公開U1位置をXY原点、PCB下面Z=0、上面Z=1.6。右の全体表示にはX+160 mmを加えるが、下表は左右のローカル座標。F3Dは組立位置を保持する。今回の電池単体STEPは部品ローカル座標なので、搭載位置はF3DまたはJSONを見る。

| 要素 | 左の範囲 mm | 右の範囲 mm | 根拠 |
| --- | --- | --- | --- |
| 電池本体 | X -65〜-35、Y -50〜-30、Z -8〜-4 | X 35〜65、Y -50〜-30、Z -8〜-4 | 本体概寸を中央寄りに仮配置 |
| 搭載用の仮余裕 | X -66〜-34、Y -51〜-29、Z -9〜-3.5 | X 34〜66、Y -51〜-29、Z -9〜-3.5 | 32×22×5.5の設計仮定。電池メーカーの膨張仕様ではない |
| PCB下面部品の予約空間 | PCB外接矩形、Z -3〜0 | 同左 | ソケット高さに対して余裕を置いた比較用スラブ。MCU等の全実装を表さない |

電池本体上面と予約空間の間は1 mm、仮余裕上面とは0.5 mm。配線・コネクタ・絶縁・固定方法の詳細は未解決。両側とも仮余裕のXY周囲220点を0.5 mm刻みでPCBへ投影し、PCB材料外の点は0だった。これは周囲のサンプル検査で、輪郭の厳密な包含や実装部品との干渉なしを証明するものではない。電池の配置後の組立包絡と履歴エラーなしを別途APIで確認した。

締結は底面M2ねじ＋上側ボスを第一比較案として、各側4軸をPCB外接矩形の左右5 mm外に置いた。φ6のボス候補とφ2の軸を構築円で示すだけで、穴・タップ・ボスの実体は作っていない。基板を貫通しない案なので、旧左で塞いだ穴を利用できると仮定しない。PCB支持は別途プレートまたは基板縁の支持から決める。

この外接矩形ベースの案には外形が膨らむ欠点がある。ボス半径3 mmまで含む最小X方向包絡は左右それぞれ約139.94 mmとなり、壁の余肉はさらに必要。最終4本を決定したわけではなく、次は実際の輪郭の近くへ移動して外形と工具アクセスを比較する。右側はCOROPITの位置が決まるまで軸位置を確定しない。

## 5. 底厚とスタンドの積み上げ

比較用に内部床Z=-9.5 mmを置くと、電池の仮余裕下面Z=-9との間は0.5 mm。通常の底厚を仮に2 mmとすれば外側底面Z=-11.5 mmになる。深さ3.7 mmのスタンドくぼみを同じ領域に追加すると底を抜くため、この積み上げでは成立しない。

くぼみ床との残肉2 mmを確保するには、その部分の外側底面はZ=-15.2 mm以下が必要（内部床-9.5、残肉2、くぼみ3.7）。これは強度・加工可能性を認定した値ではないが、電池とくぼみの重なりが高さを増すことを示す。次は電池とくぼみのXY重複を避ける配置を優先し、スタンドの支持点・展開向き・指掛かりを合わせて比較する。

## 6. 次に作るものと残る確認

1. スイッチのプレート開口・局所厚さ・爪逃げをパラメータ化した独立LP支持部。実物未試験なので係止は仮仕様。
2. 電池とスタンドくぼみの重複を避け、外側ボスを輪郭へ寄せた配置B。左右の基板縁支持、配線経路、USB、XIAOアンテナ周囲も設計する。
3. COROPITの本体最大外形、固定面から球中心までの高さ、M1.7の有効ねじ長、コネクタ位置を確認し、右側の禁止領域を確定する。

部品の未確認事項は、ソケット型番・向き、キーキャップ、実基板の版とLP加工状態、XIAOの実装高さ・向き、COROPIT外形、左右の電池寸法、テープ厚。既知の情報だけで仮配置を進められるが、現状のモデルを発注用には使わない。JLCCNC向けには将来、ケースの部品別STEPと、ねじ・公差・表面処理等を指示する図面を別途作る。
