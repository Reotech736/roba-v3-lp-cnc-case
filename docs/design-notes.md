# 設計ノート

## CNC加工向け設計の考慮点

### 1. 3Dプリントとの違い

- **薄肉部分**: 3Dプリントでは0.8-1.2mm程度でも問題ないが、CNCでは最低1.5-2.0mm以上推奨
- **ツメ固定**: 柔軟性が必要な部分は設計変更が必要
- **アンダーカット**: 3軸CNCでは加工できないため、分割や設計変更が必要
- **コーナーR**: エンドミル径に応じた内側コーナーRが必要（通常R0.5mm以上）

### 2. JLCCNC向け最適化

- **素材選定**: アルミ6061（一般用途）または7075（高強度）
- **表面処理**: ビードブラスト + アルマイト処理
- **公差管理**: 標準公差±0.1mm、嵌合部は±0.05mm指定可能
- **最小加工径**: エンドミル径を考慮（通常φ1.0mm以上）
