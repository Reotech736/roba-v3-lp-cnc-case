# 部品CADの再利用と仮包絡

更新: 2026-11-08。ケース自体を新規設計する方針は、既製部品のCADを再利用しないという意味ではない。型番・版が合う既存モデルを優先して使う。

## 現在の使い分け

- **詳細な参照モデル:** USB、リセットボタン、部品の局所形状と配置を確認するために使う。元データは編集せず、新ケースに独立した参照コピーを配置する。
- **仮包絡:** 部品寸法の余裕、配線・指・ケーブルの動作空間などを調べる検査用。詳細モデルがあっても必要だが、精密部品モデルと同じものとして表示・説明しない。
- **図面からの仮形状:** 一致する部品CADがまだない箇所に限る。採用した寸法の基準と未モデル化の部分を明示する。

## XIAO

旧 `roba-v3-lp-cnc-case_old/xiao-nrf52840-v3` v2を77ボディのままSTEPへ書き出し、新ケースへ取り込んだ。旧データはv2・未変更のまま保持。仮包絡は非表示の検査用として残し、詳細参照を表示する。

旧ネイティブ座標はX=長さ、Y=厚さ、Z=幅。新ケースには `X'=Z+6.1114, Y'=X−12.28166, Z'=Y+1.85` mmで配置した。旧ケースの組立変換を継承したのではなく、既存の公開PCB上面Z=1.6とUSB前端の仮基準へ合わせたもの。最高部Z=6.06、幅17.78、PCB長さ20.955。はんだ間隔、実機の版、元モデルの取得元との一致は未確定。

上下ケース・カバーとの体積干渉は検出されなかった。詳細モデル内部には12件の重なりが報告されるため、部品内部の重なりとケースとの干渉を分けて記録した。[検証JSON](detailed-xiao-reference-verification.json)。

生の参照STEP: `cad/reference/components/xiao-nrf52840-v3_old_v2.step`。SHA-256: `863224f173b530743740035ab59647ca9957b3d9f9cb1d4a1f87220481827cbe`。元クラウドIDは検証JSONに記録。元モデルの公開ライセンス・取得元は不明のため、メーカー配布品と断定しない。

[Seeed公式資料](https://wiki.seeedstudio.com/XIAO_BLE/#resources)にはKiCad・DXF等があり、明示されているSTEPリンクはSense版。非Sense版の代替として無条件に取り込まず、今回の旧モデルと実機の照合用資料にする。

## スイッチ・ソケット

[koktoh/keyswitch_model](https://github.com/koktoh/keyswitch_model)のChoc V2 Redとソケットを、ユーザーのChoc V2として進める確認を受けて取り込んだ。各23個を配置し、全46原点の位置を履歴確定後に検査。固定コミット・ハッシュ・CC BY-NC-SA 4.0表記をcad/reference/third-party/koktohに保存し、本リポジトリのGPL表記に一括で含めない。Spring Mini同一品番のメーカー認定モデルとは扱わない。

[ai03/MX_V2](https://github.com/ai03-2725/MX_V2)にもPG1353用フットプリント・3D参照があるが、フットプリントの向きやソケット版の差に注意する。汎用Choc V2の見た目が似ているだけでは、Spring Miniの爪保持や着座高さの確定には使わない。

詳細Choc V2は軸上端8.6 mmで[メーカー図面](https://www.kailhswitch.com/uploads/15927/files/CPG1353D01D01-24-data-sheet.pdf)から求めた公称高さと一致する。下側14 mm・上側15.2角の包絡は別の検査用に非表示で残す。詳細ソケットで見つかった支持部干渉は移設して解消した。[最新記録](choc-reference-and-cover-development.md)。実物ソケットの型番・方向とPCB機能穴は未照合。
