## 次に取り組む順番

1. **LPスイッチとソケットの仕様を照合する。** 正式型番、必要なプレート開口・厚さ、PCB表裏の高さを確認。公開v2のフットプリントや旧左の追加孔を、実物LP仕様そのものとみなさない。旧基板の編集内容は比較資料として使える。
2. **COROPITのモデル・固定部・可動域を調べる。** ケース参照STEPの開口だけでは、本体・配線・指の空間を確定できない。独立した参照を探す。
3. **新しい座標系で内部部品を仮配置する。** 電池は配線・コネクタ・固定材・絶縁を含む余裕を追加。MCUはユーザー申告XIAO nRF52840。アンテナ周辺の構成も検討する。
4. **基板支持と上下ケースの役割を決める。** 作業仮説は上側でスイッチ・基板の位置を決め、下側を外して整備する構成。底面ねじ＋上側タップボス＋位置決め段を第一比較候補にする。ねじ径・本数・位置は未決定。
5. **新規ケース形状を作る。** 必要空間から外形・高さ・壁厚・底厚を決める。スタンドくぼみと電池、ねじ、基板、COROPITとの重なりを検証する。旧ケースの薄肉寸法やくぼみ位置は流用しない。

## 後でユーザーと確認したい情報

- キースイッチの正式名称（分かれば購入履歴）、ソケット・キーキャップの仕様。
- 基板上の版表記。v2の可能性はあるが未確定。
- COROPITの製品情報・固定部寸法、左右の電池が同じか。
- 電池の端部を含む最大寸法、スタンド厚さ4 mmにテープを含むか、スタンドの個数・開く向き。

これらが未確認でも参照調査や仮配置は進められる。試作・金属加工発注の前に、実物での適合・開閉・操作・通信確認が必要。手元に3Dプリンタはないので、試験時期は未定。
