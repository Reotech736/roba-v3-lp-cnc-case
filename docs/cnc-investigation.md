## 測定方法と保護状態

Fusion MCPで `01_source_roBa` のケースを開き、APIドキュメントを確認後、`execute/script` の `readOnly=true` で読み取った。UI操作は使用していない。長さは内部単位cmからmm、体積はcm³からmm³へ換算。外形は `BRepBody.preciseBoundingBox` による元座標の軸平行包絡寸法で、素材寸法や有効内寸ではない。面の包絡値は `BRepFace.boundingBox`。丸め前に近い測定値、円筒面、主要平面は [測定記録](fusion-case-measurements.json) に保存。

終了時に参照6点すべて `DataFile.isReadOnly=true`、`isComplete=true`、version 1、開いた4文書すべて `isModified=false` を確認。開く操作の応答には `isReadOnly=false` と出たが、DataFileの直接照会は全件trueだったため、両応答を区別した。読み取り専用設定の切替、保存、複製、STEP更新はしていない。

## 特徴と加工上の調査対象

- トップの広い水平面は左Z=2.6/3.8 mm、右Z=2.61/3.8 mm。段差はそれぞれ1.20/1.19 mm。右にはZ=1.6 mmの広い面もある。機能面の候補だが、PCB支持面などの用途は部品モデルで確認する。
- ボトムの最大平面の幾何法線は左(-0.06976, 0, -0.99756)、右(+0.06976, 0, -0.99756)。Z軸に対し約4°傾斜し、傾斜方向は左右で逆。底面・内側面候補の面積は左8554.60/8089.82 mm²、右9044.70/7106.20 mm²。面法線の向きは材料側を保証しない。傾斜面の反転保持や基準の取り方を確認する。
- 右ボトムにはZ=-2 mm、面積1632.14 mm²の水平面があり、左の主要平面一覧とは異なる。右トップにも独自の段差があるため、COROPIT周辺は左右反転で済ませず個別に調査する。
- 左右トップのZ=-3〜-2 mm付近にR0.25、長さ約3.5 mmの横軸円筒面が複数ある。固定用ツメ周辺の候補であり、機能の断定はしていない。R0.25はモデル中の円筒面半径で、最小内側Rや必要工具半径を示す値ではない。
- トップにはR0.5の細部とX/Y方向を軸とする円筒面もある。側面加工・アンダーカット・工具干渉の確認対象。円筒面だけでは穴径や内外の凹凸を判定できない。
- 最小肉厚、ポケット深さ、全内側R、開口の有効寸法、ネジ穴位置は今回未測定。外形値から推定して確定しない。

## 次に必要な調査

1. `02_design` に確認用の複製または参照アセンブリを作り、元座標の上下が正しいか現物で照合する。
2. 基板版を特定し、PCB・スイッチ・電池・COROPITと操作部品のモデルまたは実測寸法を揃える。特に左v3共通ボトムの適合を確認する。
3. 上下の断面、実体干渉、支持面・ツメ・開口を同定し、局所肉厚と工具の到達性を測る。
4. 固定方式とアンテナ・絶縁の方針を決め、片側の設計用複製で変更案を具体化する。

現時点では組立・加工適合は未検証で、元STEPを加工発注には使用しない。
